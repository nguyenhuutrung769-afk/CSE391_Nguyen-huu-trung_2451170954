API đã dùng
- [JSONPlaceholder Users](https://jsonplaceholder.typicode.com/users)

Cách chạy
1. Mở file `index.html` trong trình duyệt
2. App sẽ tự động load danh sách users từ API
3. Chức năng:
   - **READ**: hiển thị danh sách users dạng card
   - **CREATE**: form thêm user mới (POST)
   - **UPDATE**: edit user (PUT)
   - **DELETE**: xóa user (DELETE)
   - **SEARCH**: lọc theo name/email
   - Loading skeleton + error toast
